
## Verified proof spine

### 1. Critical `L^3` / physical Lamb reduction

R01–R08 isolate the critical `L^3` pressure obstruction. With

```text
L = omega × u,
G = |u|u,
U = ||u||_(3/2),
```

R03/R05 give the complementary exact pressure-work representations

```text
W_3 = <Q L,Q G> = -<P L,P G>.
```

R18 proves that divergence of the surviving tail action forces the **untruncated physical Lamb action**

```text
A_L = ∫ U ||L||_2^2 dt
```

to diverge through arbitrarily high physical Fourier outputs. R20 proves high Lamb output cannot be generated by two inputs both confined below half the output scale.

### 2. The nonlinear test field is transported-speed geometry, not raw `|u|` UV

R22–R23 give

```text
Q(|u|u) = Q[(curl^-1 u) × grad|u|] = [Q,|u|]u.
```

R24 identifies the scalar actually seen by the projection. With `rho=|u|`, `e=u/rho` on `{rho>0}` and `S=sym grad u`,

```text
q_amp = div(rho u)
      = u·grad rho
      = u^T S u / rho
      = rho e^T S e
      = -rho^2 div e,
Q(rho u) = grad Delta^-1 q_amp.
```

RD013 shows why this matters: a smooth velocity supported only on fundamental modes can have infinitely many harmonics in `|u|` while still satisfying `Q(|u|u)=0`.

### 3. Balanced P/Q obstruction

R26 proves a solenoidal critical-action criterion complementary to R06's Bernoulli-gradient criterion.

R27 then defines

```text
A_bal
  = ∫ U min(||P L||_2^2, ||Q L||_2^2) dt
```

and proves that finite `A_bal` controls the same endpoint `L^3` barrier. Thus a singular endpoint in this framework forces even the **pointwise weaker Helmholtz channel** to accumulate non-summable critical action.

RD014 prevents overinterpretation: global P/Q balance does **not** imply same-shell balance.

### 4. R28–R29: productive UV is one cumulative common mode

R28 proves that if the endpoint `L^3` quantity diverges, then for every fixed cutoff `K`, both exact high-pass representations carry unbounded net positive pressure work:

```text
∫ W_grad,>K dt -> +infinity,
∫ W_sol,>K  dt -> +infinity.
```

R29 then proves the exact mismatch identity

```text
W_grad,>K - W_sol,>K
  = -<Pi_<=K L,Pi_<=K G>.
```

The high-pass P/Q mismatch is therefore entirely a **low-frequency compensator**. For every fixed `K` it is time-integrable, and on shrinking terminal windows its integrated contribution tends to zero.

So the two productive UV representations are asymptotically one cumulative common mode, not two independent singular processes.

### 5. R30: the minority tail itself escapes every fixed scale

Define

```text
A_bal,>K
 = ∫ U min(
     ||Pi_>K P L||_2^2,
     ||Pi_>K Q L||_2^2
   ) dt.
```

R30 proves that for **any fixed finite `K`**, finite `A_bal,>K` controls the endpoint `L^3` barrier. Hence a singular endpoint must satisfy

```text
A_bal,>K(T*) = infinity
```

for every fixed `K`.

The weaker Helmholtz tail cannot keep its divergence trapped in bounded frequencies.

### 6. R31: synchronized diagonal terminal packets

For arbitrary

```text
K_n -> infinity,
epsilon_n -> 0,
M_n -> infinity,
```

R31 extracts finite terminal intervals `I_n=[a_n,b_n] -> T*` on which, simultaneously,

- gradient productive work is at least `M_n`;
- solenoidal productive work is at least `M_n`;
- balanced high-pass action is at least `M_n`;
- the two integrated productive works differ by at most `epsilon_n`.

This gives a compactness-ready frequency/time sequence, though no nontrivial rescaled limit or contradiction is yet proved.

### 7. R32: compensator improves from cubic to quadratic lattice scale

R32 combines Hausdorff–Young, interpolation and enstrophy to improve the sharp low-frequency defect to

```text
|D_K|
 <= C N_K^(2/3) E0^2 ||omega||_2^2.
```

Since `N_K` is cubic in the lattice scale, this corresponds to approximately `K^2`, improving the earlier `K^3` counting behavior. The integrated mismatch is controlled by the **actual terminal enstrophy tail**, which tends to zero.

R32 still does not provide a universal parabolic-scale modulus as `K->infinity`.

### 8. RD015: no hidden sharp-ball `L^p` shortcut

RD015 forbids silently treating the sharp spherical cutoff as a `K`-uniform smooth Littlewood–Paley multiplier for `p != 2`. The guard is motivated by Fefferman's classical ball-multiplier obstruction.

Safe sharp-cutoff uses remain `L^2` orthogonality/contraction, finite-mode counting and Hausdorff–Young estimates with explicit cutoff dependence.

### 9. R33: exact smooth square partition and pure commutator defect

R33 replaces the dangerous sharp-multiplier interface by smooth self-adjoint filters satisfying

```text
M_K^2 + H_K^2 = I.
```

The square partition preserves the exact work algebra even though the filters overlap:

```text
W_3 = <M QL,M QG> + <H QL,H QG>
    = -<M PL,M PG> - <H PL,H PG>.
```

Most importantly,

```text
W_grad,H - W_sol,H
  = -<[M_K^2,C_u] omega, |u|u>,
C_u omega = omega × u.
```

The smooth P/Q synchronization defect is therefore a **pure Fourier/multiplication commutator**, not a generic product.

### 10. R34: the smooth commutator framework is load-bearing

Choose `M_K` with compact low support and `H_K^2=I-M_K^2`. Smooth low-filter work is energy-integrable, while high-filter test fields retain the R06/R27 diffusion bounds by `L^2` contraction.

Define

```text
A_bal,H^K
 = ∫ U min(
     ||H_K P L||_2^2,
     ||H_K Q L||_2^2
   ) dt.
```

R34 proves that a singular endpoint forces, for every fixed smooth scale `K`,

```text
A_bal,H^K = infinity,
∫ W_grad,H dt -> +infinity,
∫ W_sol,H  dt -> +infinity.
```

Thus the R33 commutator is attached directly to the surviving singular obstruction.

### 11. RD016: generic stress/Hölder/Bernstein goes backward

Optimizing the template

Therefore any genuine improvement must retain structure that generic stress/Hölder estimates discard.

### 12. R35: low-frequency velocity modulation is commutator-small

Let `A_K=M_K^2` have smooth scaled symbol `a_K(xi)=a(xi/K)`. R35 computes

```text
widehat([A_K,C_u]omega)(k)
 = sum_{p+q=k}
   [a_K(k)-a_K(p)]
   [omega_hat(p) × u_hat(q)].
```

The exact symbol obeys

```text
|a_K(p+q)-a_K(p)|
 <= min(
      2||a||_infinity,
      ||grad a||_infinity |q|/K
    ).
```

Hence velocity modulation with `|q| << K` carries an explicit `|q|/K` gain. A constant velocity multiplier contributes exactly zero.

The remaining dangerous commutator regimes must therefore involve velocity input at/above the active scale, or a sufficiently large accumulation that overcomes the individual symbol gain.

## Canonical E35 obstruction

A hypothetical singular trajectory compatible with the current proof spine must sustain all of the following:

1. **common productive UV work** — the P/Q high-frequency work representations differ only by an integrable low/commutator defect;
2. **balanced minority UV strength** — the weaker Helmholtz Lamb tail has divergent critical action above every fixed sharp or smooth scale;
3. **terminal diagonal packets** — `K_n->infinity`, `I_n->T*` can be chosen with arbitrarily large productive work/action and arbitrarily small integrated P/Q mismatch;
4. **finite enstrophy-tail mismatch** — R32 bounds the defect at the generic `~K^2` scale;
5. **smooth commutator structure** — the defect is exactly `<[M_K^2,C_u]omega,|u|u>`;
6. **high-input requirement** — R35 suppresses low-frequency multiplying velocity by `|q|/K`.

This is substantially more rigid than the E28 picture of two possibly separated productive UV sequences.
