# R20 — Physical Lamb ultraviolet output requires high-frequency velocity input

**Status:** `exact Fourier-support reduction / not claimed novel`  
**Depends on:** R18–R19  
**Clay status:** no summable high-frequency input estimate is proved

R18 proves that if the R08 tail obstruction diverges at a finite time `T*`, then the **untruncated physical Lamb action**

`A_L(T*) = int_0^{T*} ||u||_(3/2) ||omega×u||_2^2 dt`

diverges, and its action escapes every fixed output Fourier cutoff.

R20 makes the next exact step: such ultraviolet output cannot be generated by interactions of two uniformly low-frequency velocity inputs.

Let `S_{<=K}` and `S_{>K}` denote sharp Fourier projectors on the periodic torus with respect to the Euclidean wave-number magnitude. Write

`u_l = S_{<=K/2}u`, `u_h=S_{>K/2}u`,

and, since curl commutes with Fourier projection,

`omega_l=curl u_l`, `omega_h=curl u_h`.

Set `L=omega×u`.

## 1. Exact low-low exclusion

For every Fourier mode in `omega_l×u_l`, the output wave vector is `k=p+q` with

`|p|<=K/2`, `|q|<=K/2`.

The triangle inequality gives `|k|<=K`. Therefore

> `S_{>K}(omega_l×u_l)=0`.

No cancellation, PDE estimate, or regularity assumption is used here; this is a pure support statement.

Expanding the Lamb force then gives the exact identity

> `S_{>K}L`
>
> `= S_{>K}[omega_h×u_l + omega_l×u_h + omega_h×u_h]`
>
> `= S_{>K}[omega_h×u + omega_l×u_h]`.

Thus every physical Lamb output above `K` contains at least one velocity input above `K/2`.

## 2. Quantitative interaction-action consequence

Orthogonal projection is an `L^2` contraction, so

`||S_{>K}L||_2`

`<= ||omega_h×u||_2 + ||omega_l×u_h||_2`.

Hence

> `||S_{>K}L||_2^2`
>
> `<= 2||omega_h×u||_2^2 + 2||omega_l×u_h||_2^2`.

Define the two high-input interaction actions

`I_HH/HL(K,T)=int_0^T ||u||_(3/2) ||omega_{>K/2}×u||_2^2 dt`,

`I_LH(K,T)=int_0^T ||u||_(3/2) ||omega_{<=K/2}×u_{>K/2}||_2^2 dt`.

Then

> `A_L^{>K}(T) := int_0^T ||u||_(3/2)||S_{>K}L||_2^2 dt`
>
> `<= 2 I_HH/HL(K,T) + 2 I_LH(K,T)`.

Therefore, if R18 gives `A_L^{>K}(T*)=infinity`, at least one of the two high-input interaction actions is infinite.

This does **not** identify which input channel diverges and does not control either one.

## 3. Channel-wise version for R19

The Leray `P`, gradient `Q`, and sharp Fourier projectors commute because they are Fourier multipliers. Both `P` and `Q` are `L^2` contractions. Hence the same high-input decomposition can be projected into either R19 channel.

For `C` equal to `P` or `Q`,

> `S_{>K} C L = S_{>K} C[omega_h×u + omega_l×u_h]`.

Thus a divergent solenoidal UV branch and a divergent Bernoulli-gradient UV branch both require actual high-frequency velocity input; neither can be sustained solely by low-low interactions.

## 4. Bridge to independent frequency-local regularity programs

This theorem gives a clean interface to Littlewood–Paley regularity criteria expressed directly in the velocity or vorticity rather than in the Lamb force.

Grujic–Bradshaw prove regularity criteria in which only a finite moving window of Littlewood–Paley velocity frequencies needs to remain subdued near a possible singular time. Cheskidov–Dai give a high-frequency vorticity criterion involving the short-time integral of `||Delta_q omega||_infinity`.

R20 does **not** derive either criterion from R18, nor conversely. It only removes a representation gap: genuine high-output physical Lamb action cannot hide entirely inside bounded low-frequency velocity input.

Primary references:

- Z. Grujic and Z. Bradshaw, *Frequency localized regularity criteria for the 3D Navier-Stokes equations*, arXiv:1501.01043.
- A. Cheskidov and M. Dai, *Regularity criteria for the 3D Navier-Stokes and MHD equations*, arXiv:1507.06611.

## 5. Surviving unknown after R20

The missing theorem is now more specific:

> obtain a trajectory-level, scale-critical, summable estimate on the high-input interactions forced by R20, or connect their divergence to a known frequency-local velocity/vorticity regularity criterion strongly enough to obtain a contradiction.

Simple support propagation alone cannot do this: high input is necessary for high Lamb output, but energy control does not make the critical high-frequency interaction action summable.

The checker is a support certificate only; it does not simulate Navier–Stokes or certify global regularity.
